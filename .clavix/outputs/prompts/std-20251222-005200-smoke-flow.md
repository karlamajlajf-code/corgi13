# Improved Prompt

## Objective

Add a DB-backed end-to-end API happy-path smoke test for the canonical tejospec stack.

## Scope

- Create a Node script at `tejospec/scripts/smoke-flow.mjs` that executes:

  1. GET `/health` and require DB status `up`
  2. POST `/auth/register`
  3. POST `/auth/login` and capture JWT
  4. GET `/products` and choose a product
  5. POST `/cart/items` to add product to cart
  6. POST `/orders` to create an order
  7. GET `/orders` to verify orders can be listed

- Wire scripts in `tejospec/package.json`:

  - `smoke:flow` (primary)
  - `smoke-flow` (Nx-friendly alias)

- Update the single authoritative plan file `tejospec/docs/MASTER_PLAN.md`:
  - Document the new command(s) under "Run Live (Local)"
  - Add a completed task checkbox entry
  - Add a Change Log entry

## Constraints

- pnpm-only
- Keep Nx compatible: avoid breaking the Nx project graph and keep root `nx` config minimal
- Do not change Next router architecture or Nest module structure

## Acceptance Criteria

- `pnpm smoke:flow --help` exits 0 and prints usage
- When DB is not configured/up, the flow smoke exits non-zero with actionable instructions
- When DB is configured and seeded, the flow smoke returns `PASS: flow smoke`
- `MASTER_PLAN.md` reflects the new command and completion
