# Improved Prompt

## Objective

Review the latest full Chromium E2E run output and confirm the suite status. If any failures remain, identify the failing specs and apply minimal, test-only stabilizations (auth seeding, route stubs, guarded assertions) to get the suite green.

## Scope

- Inspect the latest full-run output file for pass/skip/fail status.
- If failures exist, update only the affected Playwright specs or shared fixtures under `tests/e2e/`.
- Prefer test stabilization techniques (e.g., `seedAuthState`, `page.route` stubs, optional assertions) over production code changes.
- Re-run the narrowest affected specs first; run the full Chromium suite only if needed to confirm everything is green.

## Constraints

- Use Nx to run tests (`pnpm -s nx run @tejo/root:e2e ...`).
- Keep changes minimal and limited to E2E test code unless a production fix is unavoidable.
- If the suite is already green, make no code changes and only report results.

## Acceptance Criteria

- The latest suite run is confirmed (0 failures). If failures existed, they are resolved and re-verified.
- Any changes are limited to E2E tests/fixtures and are clearly summarized.
- Provide a concise report with how to validate.
