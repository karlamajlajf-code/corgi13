# Improved Prompt

## Objective

Add additional visible UI enhancements to the storefront to increase engagement and urgency without breaking existing layout or interactions.

## Scope

- Create two new UI components:
  1. **DeliveryCountdown**: a floating pill showing “Order in Xh Ym for verzending vandaag” with live countdown, dismissible, desktop-only.
  2. **ReferralCTA**: a floating mini card promoting “Geef €5, krijg €5” referral, with CTA button and dismiss control, desktop-only.
- Integrate both components into `Layout.tsx` so they render globally with other UI overlays.
- Keep placements non-conflicting with existing overlays (top-left loyalty, top-right stock alert, mid-left POTD, bottom-right chat/newsletter, bottom strips brand/trust).
- Maintain existing design language (dark theme, tailwind, lucide icons, subtle animations).

## Constraints

- TypeScript strict; no runtime errors.
- Tailwind classes consistent with current codebase; prefer existing patterns for gradients/rounding/shadows.
- Desktop-only visibility (`md:block`), avoid crowding on mobile.
- Use safe timers (cleanup on unmount) and local/session storage for dismissal persistence if used.

## Acceptance Criteria

- New components live in `apps/web/src/components/ui/DeliveryCountdown.tsx` and `ReferralCTA.tsx` (or similar), exported functions.
- `Layout.tsx` imports and renders both components in sensible positions that do not overlap existing overlays.
- `pnpm nx run @tejo/web:typecheck` passes.
- `pnpm nx run @tejo/web:lint` passes.
- Site reachable at `http://localhost:3003` (200 OK) after changes.
