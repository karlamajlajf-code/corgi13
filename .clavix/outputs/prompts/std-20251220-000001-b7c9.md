# Improved Prompt

## Objective

Make GitHub Copilot Chat (VS Code Insiders) run a “full Clavix pipeline” automatically for every user message in Agent mode, so I can type normal prompts like “continue” and the agent will:

1. improve/structure the request,
2. implement the change(s),
3. verify (tests/build),
4. report results.

## Context

- This repo uses Clavix (agentic-first). There is no true runtime hook, so the best implementation is deterministic routing via repository Copilot instructions and optional VS Code workspace settings.
- Current behavior is “Improve by default, implement only on explicit request”. Change it to “Full pipeline by default”.

## Requirements

### Default behavior (EVERY message)

For any user message in Copilot Agent mode:

1. **Interpret the user’s message as a task request** (even if short like “continue”).
2. **Run a lightweight improvement step**:
   - Rephrase the message into a structured, implementation-ready prompt with sections: Objective, Scope, Constraints, Files to Touch, Acceptance Criteria.
   - If there are critical ambiguities that prevent safe work, ask one clarifying question (otherwise proceed).
3. **Implement immediately**:
   - Make the necessary file changes in the repo.
   - Prefer minimal, targeted edits.
4. **Verify**:
   - Run the most relevant, narrow tests first (or typecheck/build if tests don’t exist).
   - If verification fails, fix issues that are directly caused by the change.
5. **Report**:
   - Summarize what changed and how to validate.

### Safety / escape hatches

- If the message starts with `!` then DO NOT implement; only do the improvement step and stop.
- If the message starts with `VERIFY:` then perform a read-only spec-driven verification and do not modify code.
- If the message starts with `PROMPT:` then only improve/save the prompt and stop.

### Compatibility

- Keep support for explicit `/clavix:` or `/clavix-` commands (treat as Clavix invocation).
- Keep nested AGENTS.md instructions enabled.

## Implementation Tasks

1. Update the repository Copilot instruction router so that default mode is “Full pipeline” (improve → implement → verify) for every message, with the safety escape hatches above.
2. Ensure workspace settings enable nested AGENTS.md instructions.
3. Add a short “How to use” section explaining:
   - Normal prompts run full pipeline automatically.
   - `!` disables implementation.
   - `VERIFY:` runs verification only.

## Acceptance Criteria

- In VS Code Copilot Chat Agent mode, sending “continue” triggers a full workflow (improve → implement → verify) without needing any special prefix.
- Sending `!continue` does not edit files and only returns an improved prompt.
- Sending `VERIFY: ...` performs read-only verification.
