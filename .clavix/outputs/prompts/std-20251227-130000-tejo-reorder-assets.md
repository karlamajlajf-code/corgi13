# Improved Prompt: Tejo Beauty — Reorder Automation Assets (Day 14 / Day 28)

## Objective

Create simple, copy/paste retention assets that maximize **second-order rate** for wholesale buyers.

## Context

- Tejo Beauty is a Croatia-based EU importer.
- Wedge: wholesale-first (salons/retailers)
- Strategy: operational trust + reorder certainty.

## Requirements

### A) Reorder scripts

Produce scripts for:

- Day 14 WhatsApp
- Day 14 email
- Day 28 WhatsApp
- Day 28 email
- “Not yet” deferral response
- “What should I reorder?” response

Rules:

- single keyword CTA: RESTOCK
- easy opt-out line
- short and operational

### B) Reorder tracker template

Produce a CSV template that supports:

- first order date/value
- next scheduled touch date
- next step
- notes

Include 2 example rows.

## Deliverables

- `tejospec/docs/growth/REORDER_SCRIPTS.md`
- `tejospec/docs/growth/REORDER_TRACKER_TEMPLATE.csv`

Also update the Trust Pack and outreach plan to reference these assets.

## Acceptance Criteria

- A non-technical operator can schedule Day 14/28 touches immediately.
- Scripts are short, single-CTA, and consistent with the wholesale positioning.
