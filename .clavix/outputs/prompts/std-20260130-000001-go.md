# Improved Prompt

## Objective

Continue the modernization/migration work after completing Phase 2.1 account pages. Identify the next highest-priority web pages that still use legacy API calls (e.g., `fetch('/api/...')` or `@/lib/api` `get/post/del`) and migrate them to the server-actions + client hooks pattern used in Phase 2.1.

## Scope

- Search `apps/web/src/pages` (and closely-related components if needed) for legacy API calls.
- Prioritize pages that are user-facing and high-traffic (checkout, contact, auth, etc.), and migrate them in order of impact.
- Add any missing server-actions and hooks required to support these pages.
- Update UI to use proper loading/error states with React Query hook results.
- Keep changes localized to the migrated pages and their required hooks/actions.

## Constraints

- Use existing patterns from Phase 2.1 (React Query hooks in `lib/hooks/use-server-actions.ts` + server actions in `lib/server-actions.ts`).
- Keep data shape/type handling safe; convert errors to string messages for UI display.
- Do not refactor unrelated code or fix pre-existing typecheck errors outside the touched files.
- Prefer Nx for running checks (e.g., `nx run apps/web:typecheck`) when validating.

## Acceptance Criteria

- Each selected page no longer calls legacy API helpers or raw `fetch('/api/...')` directly; it uses server-actions hooks instead.
- Any required server actions/hooks are implemented with consistent error handling and revalidation tags.
- UI shows loading and error states based on hook results.
- TypeScript passes for the touched files (and related hooks/actions).
- Provide a concise summary of what was migrated and how to validate.
