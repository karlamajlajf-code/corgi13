## Execution / Implementation Report

### What Was Implemented

This prompt was executed by enhancing an existing authentication system (rather than building one from scratch) inside the `tejospec` project.

Key behaviors implemented:

- **Access vs refresh token separation**
  - Access token expiry: **15 minutes**
  - Refresh token expiry: **7 days**
  - Refresh tokens are minted/verified with a **separate secret** (`REFRESH_SECRET`).
- **Refresh endpoint hardening**
  - `/auth/refresh` validates refresh tokens only and issues a new access token.
  - Refresh token rotation is implemented (new refresh token is issued on refresh).
- **Middleware enforcement**
  - Customer auth middleware rejects refresh tokens for API requests (only access tokens are accepted in `Authorization: Bearer ...`).
