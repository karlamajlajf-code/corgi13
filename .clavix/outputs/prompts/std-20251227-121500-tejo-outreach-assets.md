# Improved Prompt: Tejo Beauty — Weeks 1–4 Wholesale Outreach Assets

## Objective

Generate execution-ready assets for Tejo Beauty’s **wholesale-first wedge** (Croatia-origin) to rapidly acquire B2B accounts and first orders in **Croatia → Slovenia → Austria → Germany (test)**.

## Scope

### A) Lead capture system

Produce a simple CSV template that can be imported into Google Sheets, with columns that support:

- country rollouts (Croatia/Slovenia/Austria/Germany)
- status pipeline (New → Contacted → Replied → Catalog Sent → Call Booked → Approved → Ordered → Reorder Due)
- next-step discipline and follow-up dates

Include 1–2 example rows with placeholder values.

### B) Outreach scripts library

Provide concise scripts for:

- first touch email
- first touch WhatsApp
- follow-up #1 (Day 2)
- follow-up #2 (Day 6 “close the loop”)
- call opener (30 seconds)
- objection handling (“why you vs big retailers like Notino?”)

Rules:

- One CTA per message
- No deceptive claims
- Easy opt-out line

### C) Starter kit offer template

Create a structured starter kit template for wholesale onboarding that includes:

- 2–3 kit tiers (e.g., Test / Core / Pro)
- recommended product mix slots (categories) rather than specific SKUs
- pricing, MOQ, payment terms, reorder triggers
- margin / MSRP sanity checks
- what data to capture after the first order (so reorder becomes automatic)

## Constraints / Guardrails

- Comply with EU reality: VAT invoice clarity, cross-border expectations, realistic delivery promises.
- Keep content short, copy/paste ready, and operational.
- Avoid any medical or regulated claims.

## Deliverables (save as Markdown/CSV)

1. `tejospec/docs/growth/LEAD_TRACKER_TEMPLATE.csv`
2. `tejospec/docs/growth/OUTREACH_SCRIPTS.md`
3. `tejospec/docs/growth/STARTER_KIT_TEMPLATE.md`
4. Update `tejospec/docs/growth/OUTREACH_WEEKS_1_4.md` to reference the tracker + starter kit template.

## Acceptance Criteria

- A non-technical operator can start outreach within 1 hour.
- CSV imports cleanly into Google Sheets.
- Scripts are short, specific, and enforce a single CTA.
- Starter kit template is usable without knowing exact SKUs yet.
